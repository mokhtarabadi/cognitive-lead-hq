### Security fixes applied (QA Engineer adversarial findings)

1. **Path Traversal prevention** — `create_tree_report` now resolves `target_path` via `Path(target_path).resolve()` and verifies the result is inside the workspace root (`Path.cwd().resolve()`) using `relative_to`. Any path escaping the project returns `"Error: Path traversal detected. target_path must be within the project workspace."` before any directory walk or file write. The `read_source_files` tool already had its own `context-reports`-scope guard, but `create_tree_report` accepted arbitrary absolute paths — now closed.
2. **TOCTOU race condition** — the previous unique-name strategy (`while report_file.exists(): counter += 1`) is a check-then-act pattern: two concurrent calls could both see the same free name and overwrite each other. Replaced with a UUID suffix (`uuid.uuid4().hex[:8]` appended to the timestamp) so filenames are unique by construction — no existence check needed. The same-second collision regression test still passes (now via UUID uniqueness).
3. **None / invalid type handling** — a malformed invocation (`create_tree_report(None)`) previously raised `TypeError` inside `Path(None)`. Now `if not isinstance(target_path, str): target_path = "."` degrades gracefully to the whole-project default, covered by `test_create_tree_report_handles_none_input`.
4. **Doc sync for the naming change** — every artifact documenting the report filename (`README.md`, `system-prompt.md` ×2 templates, `agents/cognitive-discovery.md`, `skill-templates/code-search/SKILL.md` + global copy, `CHANGELOG.md`) updated from `tree_report_<timestamp>.md` to `tree_report_<timestamp>_<uuid>.md`; CHANGELOG gained a `### Fixed` entry (Parse-Then-Append protocol).
