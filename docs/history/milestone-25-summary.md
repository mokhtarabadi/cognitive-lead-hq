- Removed the Freebuff footprint and fixed the full global upgrade chain so a binary upgrade also refreshes servers, deps, skills, agents, prompts and plugins (Task 399).
- Hardened zen-proxy's runtime with explicit failure statuses, chunked decode, SIGTERM drain, fail-loud config and a credential-free structured log (Task 400).
- Added `BRAIN_UPSTREAM_MODE` chat-completions bridging and the shared additive `tool_calls` channel (META 403, Tasks 401/402).
- Aligned zen-proxy and the Brain bridge with official OpenAI contracts: JSON `UnknownRoute`, the 1000 compaction floor and warn-on-dropped fields (Task 404).
- Added the OpenUI validity gate for native render and mirrored it into the hands protocol (9.89.0 → 9.90.0) (Task 405).
