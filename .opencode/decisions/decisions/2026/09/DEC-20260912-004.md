# DEC-20260912-004 — Task numbers live ONLY in code comments, CHANGELOG, task files, history archives, and HTML comments — never in prompt-facing Markdown prose (anti-hallucination discipline).

- Category: process
- Session: 181
- Project: cognitive-lead-hq

## Verbatim (original)

> توی فایل‌های مارک‌دان و مخصوصاً فایل‌های مارک‌دانی که برای پرامپت قراره استفاده بشه، به شماره تسک‌ها هم ریفرنس می‌دی. این کار باعث ایجاد توهم برای هوش مصنوعی می‌شه و جالب نیست.

## Verbatim (English)

> In Markdown files, especially Markdown files meant to be used as prompts, you also reference task numbers. This causes hallucination for the AI and it is not good.

## Rationale

Manager observed task-number references in prompt Markdown causing AI hallucination; code comments are fine and welcome.
