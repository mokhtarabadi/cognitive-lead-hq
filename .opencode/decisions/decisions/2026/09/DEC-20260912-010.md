## Verbatim (English)

> Judge yourself: the system I designed for you — judge it. Start a fresh task, a self-judgment task on yourself and the system-prompt personas. First plan it with Brain architecture, brainstorm, search the internet via the blowsh skill, find the flaws, then walk the flow and state machine yourself on active autopilot.

## Rationale

Manager wants the system to find its own flaws against external evidence instead of waiting for him to spot them.
